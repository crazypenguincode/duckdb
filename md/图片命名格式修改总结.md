# 图片命名格式修改总结

## 修改目标

根据用户要求，修改脚本使图表命名按照原始图片标题命名，格式为：`章节号_图X.X 标题.png`，并在LaTeX中显示时移除"图X.X"前缀。

## 修改内容

### 1. 图片提取脚本 (`md/extract_all_images.py`)

**修改位置**: `save_mermaid_file` 方法

**修改前**:
```python
filename = f"{diagram['chapter']}_图{diagram['fig_num']} {diagram['title']}.mmd"
```

**修改后**:
```python
filename = f"{diagram['chapter']}_图{diagram['fig_num']} {diagram['title']}.mmd"
```

**说明**: 确保使用新的命名格式：`章节号_图X.X 标题.mmd/png`

### 2. LaTeX转换脚本 (`overleaf_test/md_to_latex_converter.py`)

**修改位置**: `convert_mermaid_to_figures` 方法

**主要修改**:
1. **标题提取模式**:
   ```python
   title_patterns = [
       r'\*\*图(\d+\.\d+)\s+([^*]+)\*\*',
       r'图\s*(\d+\.\d+)[：:]\s*([^\n]+)',
       r'图\s*(\d+\.\d+)\s+([^\n]+)',
   ]
   ```

2. **文件名生成**:
   ```python
   img_filename = f"{chapter_num}_图{fig_number} {clean_title}.png"
   img_filename = re.sub(r'[<>:"/\\|?*]', '_', img_filename)
   ```

3. **LaTeX标题处理**:
   ```python
   # 生成LaTeX图片代码，标题中移除图号前缀
   latex_figure = f"""
   如图\\ref{{{label}}}所示是{clean_title}。
   
   \\begin{{figure}}[!htb]
   \t\\centering
   \t\\includegraphics[width=0.8\\textwidth]{{images/{img_filename}}}
   \t\\caption{{{clean_title}}}
   \t\\label{{{label}}}
   \\end{{figure}}
   """
   ```

### 3. DOCX构建脚本 (`md/integrated_complete_docx_builder.py`)

**修改位置**: `get_chapter_images` 方法

**修改前**:
```python
# 匹配格式：1.1_xxx.png, 1.2_xxx.png 等
if img.name.startswith(f"{chapter_num}.") and not img.name.startswith("mermaid_"):
    images.append(img)

# 从文件名中提取图号，如 "3.2_xxx.png" -> 3.2
match = re.match(rf"{chapter_num}\.(\d+)_", filename.name)
```

**修改后**:
```python
# 匹配新格式：章节号_图X.X 标题.png
if img.name.startswith(f"{chapter_num}_图") and not img.name.startswith("mermaid_"):
    images.append(img)

# 从文件名中提取图号，如 "3_图3.2 标题.png" -> 3.2
match = re.match(rf"{chapter_num}_图{chapter_num}\.(\d+)", filename.name)
```

## 命名格式对比

### 旧格式
- **文件名**: `5.5_不同查询类型的执行时间对比含误差棒.png`
- **LaTeX标题**: `图5.5 不同查询类型的执行时间对比含误差棒`

### 新格式
- **文件名**: `5_图5.5 不同查询类型的执行时间对比含误差棒.png`
- **LaTeX标题**: `不同查询类型的执行时间对比含误差棒` (移除了"图5.5"前缀)

## 优势

1. **文件名更清晰**: 包含完整的图表信息，便于识别
2. **LaTeX自动编号**: 移除手动图号，让LaTeX自动处理编号
3. **统一命名规范**: 所有脚本使用相同的命名格式
4. **特殊字符处理**: 自动清理文件名中的特殊字符

## 使用说明

1. **重新生成图片**: 运行 `python md/extract_all_images.py` 生成新格式的图片
2. **LaTeX转换**: 运行 `python overleaf_test/md_to_latex_converter.py` 进行LaTeX转换
3. **DOCX生成**: 运行 `python md/integrated_complete_docx_builder.py` 生成DOCX文档

## 注意事项

- 需要重新生成所有图片文件以使用新的命名格式
- LaTeX编译时会自动为图表分配编号，无需手动指定
- 文件名中的特殊字符会被自动替换为下划线
- 所有脚本需要同步更新以保持一致性
