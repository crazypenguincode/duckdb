### 引用方式
在文档中可以使用以下方式引用：
```markdown
![图1.1 研究背景与技术发展趋势](images/1.1_研究背景与技术发展趋势.png)
```

### 修改图片
1. 编辑对应的mmd文件
2. 使用mermaid-cli重新生成png文件：
   ```bash
   mmdc -i "图片文件.mmd" -o "图片文件.png"
   ```
