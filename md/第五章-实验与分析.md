#### (1) 查询缓存性能测试工具

**测试工具一：布隆过滤器性能测试程序**。为了评价布隆过滤器在查询缓存中的假阳性率控制效果，本文设计了专门的测试程序来统计不同配置下的性能表现，其具体流程如下：

首先，程序初始化不同大小和哈希函数数量的布隆过滤器实例。然后，程序生成大量随机查询键值，并将其中一部分插入布隆过滤器。接下来，程序测试所有查询键值的查询性能，记录查询延迟和假阳性率。最后，程序计算平均查询延迟、内存使用量和实际假阳性率，用于评估布隆过滤器的优化效果。

**测试工具二：SQL缓存标准化测试程序**。本文实现了SQL查询标准化算法的性能测试工具，用于评估查询语句的标准化效率和缓存命中率提升效果。该工具支持多种SQL语句类型的标准化测试，包括SELECT、JOIN、CTE等复杂查询结构。

**测试工具三：持久化策略性能测试程序**。为了评估不同持久化策略的性能表现，本文开发了专门的测试工具来模拟各种数据持久化场景。该工具支持WAL格式、物化视图、混合模式等多种持久化策略的性能对比测试。

#### (2) 数据库基准测试工具

**测试工具一：TPC-H基准测试**。TPC-H (Transaction Processing Performance Council - H) 是由事务处理性能委员会制定的决策支持基准测试标准。TPC-H基准测试模拟了复杂的商业分析环境，包含8个基础表和22个复杂的分析查询。

TPC-H的主要特点包括：
- **数据模型**: 模拟批发商业务环境，包含客户、订单、商品、供应商等实体
- **查询复杂度**: 包含多表连接、聚合计算、子查询、排序等复杂操作  
- **数据规模**: 支持从1GB到100TB的多种数据规模
- **性能指标**: 主要评估查询响应时间和系统吞吐量

本文使用TPC-H基准测试来评估查询缓存系统对复杂分析查询的优化效果。

**测试工具二：TPC-DS基准测试**。TPC-DS (Transaction Processing Performance Council - DS) 是TPC组织制定的决策支持基准测试标准，相比TPC-H具有更高的复杂度和更广泛的查询模式覆盖。

TPC-DS的主要特点包括：
- **数据模型**: 模拟零售业务环境，包含24个基础表
- **查询集合**: 包含99个不同复杂度的分析查询
- **查询模式**: 覆盖报表查询、即席查询、迭代式OLAP、数据挖掘等多种模式
- **技术特性**: 支持窗口函数、ROLLUP、CUBE等高级SQL特性

```python
# 推荐的实现方式
def execute_with_persistence(query, db_path):
    """使用共享数据库文件实现跨进程缓存"""
    cmd = [duckdb_path, db_path, '-c', f"""
        SET enable_query_cache = true;
        SET query_cache_max_size = '100MB';
        {query}
    """]
    return subprocess.run(cmd, capture_output=True, text=True)

# 避免的实现方式  
def execute_without_persistence(query):
    """使用内存数据库，无法跨进程共享缓存"""
    cmd = [duckdb_path, ':memory:', '-c', query]
    return subprocess.run(cmd, capture_output=True, text=True)
```
