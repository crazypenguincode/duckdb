# 高质量图片导出解决方案

## 问题描述
原始的图片导出脚本生成的PNG图片不够清晰，影响了文档的视觉效果。

## 解决方案

### 1. 新的高质量图片提取脚本
创建了 `extract_all_images_hq.py` 脚本，专门用于生成高质量的PNG图片。

### 2. 主要改进
- **更高分辨率**: 宽度1600px，高度1200px（原来是默认大小）
- **3倍缩放**: 使用3倍缩放因子，大幅提高清晰度
- **优化配置**: 自定义Mermaid配置文件，优化字体和颜色
- **白色背景**: 使用白色背景替代透明背景，提高清晰度
- **备选方案**: 如果高质量生成失败，自动尝试标准质量
- **详细日志**: 提供详细的处理进度和错误信息

### 3. 使用方法

#### 安装依赖（如果还没有安装）
```bash
npm install -g @mermaid-js/mermaid-cli
```

#### 运行高质量图片提取
```bash
cd /Users/max/src/duckdb/md
python3 extract_all_images_hq.py
```

### 4. 输出结果
- 高质量PNG图片保存在 `images_hq/` 目录
- 生成 `高质量图片索引.md` 索引文件
- 自动创建优化的Mermaid配置文件

### 5. 质量对比
| 参数 | 原版本 | 高质量版本 |
|------|--------|------------|
| 宽度 | 默认 | 1600px |
| 高度 | 默认 | 1200px |
| 缩放 | 1x | 3x |
| 背景 | 透明 | 白色 |
| 配置 | 基础 | 优化配置 |

### 6. 预期效果
- 图片清晰度提升3倍
- 文字更加锐利清晰
- 线条更加平滑
- 整体视觉效果显著改善

### 7. 故障排除
如果遇到问题：
1. 确保已安装 mermaid-cli: `npm install -g @mermaid-js/mermaid-cli`
2. 检查Node.js版本是否支持
3. 查看生成的错误日志
4. 如果高质量生成失败，会自动尝试标准质量

### 8. 文件结构
```
md/
├── extract_all_images_hq.py     # 新的高质量提取脚本
├── images_hq/                   # 高质量图片输出目录
│   ├── mermaid-config.json      # 优化配置文件
│   ├── *.mmd                    # Mermaid源文件
│   └── *.png                    # 高质量PNG图片
└── 高质量图片索引.md             # 图片索引文件
```
