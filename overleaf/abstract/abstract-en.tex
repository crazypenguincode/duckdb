\chapter*{\zihao{-3}\heiti{ABSTRACT}}
\addcontentsline{toc}{chapter}{Abstract}
\vspace{-0.5cm}

Based on a systematic analysis of the database query processing pipeline (including components such as the parser, planner, optimizer, and executor), this study identifies the bottleneck of insufficient reuse of repeated or similar query results. In response, it innovatively proposes a dynamic caching strategy based on SQL query structure and Common Table Expressions (CTEs). This strategy, combined with Bloom filter technology, enables rapid identification and precise matching of reusable cached results, thereby bypassing part of the processing flow and directly returning cached results, significantly reducing query latency.

To improve cache hit rates and ensure the timeliness of cached data, this study designs and implements multi-dimensional cache update strategies, including the classic LRU strategy, time window-based update strategy, hybrid strategy, and a machine learning-based intelligent update strategy, allowing dynamic selection of the optimal strategy based on different application scenarios. Simultaneously, to ensure cache security and fault recovery capabilities, two persistence schemes are proposed: a cache snapshot mechanism based on sequential high-efficiency read/write operations and a persistence strategy integrated with materialized views, effectively preventing cache data loss.

This study conducted development based on the open-source OLAP database DuckDB v1.3.2 and performed systematic validation of the caching system using TPC-H, TPC-DS standard benchmarks, and various custom datasets. In TPC standard benchmark tests, the system achieved an average performance improvement of 54.2%; in specialized functional tests, it achieved an average performance improvement of 68.6%, with a maximum of 88.2%; the Bloom filter optimization realized a 9.3% query acceleration; and the innovative file system cross-process caching mechanism achieved a hundredfold performance improvement. Testing covered scenarios from simple aggregations to complex CTE queries, validating the stable optimization effect of the caching technology across different query complexities.

This research provides an effective solution for enhancing the query performance of OLAP databases, based on query caching, cache replacement, and persistence.
