\vspace{-0.5cm}

Databases, as a core component of computer systems, have always placed reliability and performance at the forefront of research and practice. Online Analytical Processing (OLAP) databases, which handle multi-source heterogeneous data and support complex analytical queries, impose even higher demands on query efficiency. To overcome performance bottlenecks, this paper focuses on the database query processing pipeline—including the parser, planner, optimizer, and executor—and proposes a dynamic caching acceleration method based on Bloom filters and machine learning to significantly enhance query speed. The main contributions of this work are as follows:

First, a Bloom filter–based dynamic caching strategy is designed. Recognizing the bottleneck of underutilized reuse of repeated or similar query results, this paper innovatively proposes a dynamic caching strategy based on SQL query structure and Common Table Expressions (CTEs). By integrating Bloom filter technology, the strategy employs a multi-level filtering architecture to enable rapid cache pre-screening. It supports query normalization and fine-grained CTE-level caching, thereby bypassing portions of the processing pipeline and directly returning cached results, which substantially reduces query latency.

Second, an intelligent cache replacement policy is introduced. To improve cache hit rates and ensure data freshness, this paper designs a multi-policy–fused intelligent cache replacement system, incorporating LRU, TTL and machine learning–based strategies. A policy coordination mechanism enables dynamic switching at runtime, while an adaptive optimization mechanism continuously refines cache replacement decisions based on performance feedback, achieving highly effective cache eviction.

Third, a multi-policy–fused persistent storage technique is developed. To guarantee cache safety and fault recovery capabilities, this paper proposes four persistence schemes: in-memory mode, WAL mode, materialized view mode, and hybrid mode. The system dynamically selects the optimal persistence strategy based on data characteristics and runtime conditions. Furthermore, an innovative and experimentally validated cross-process cache sharing mechanism based on persistence is introduced, enabling efficient inter-process data sharing and effectively addressing the challenge of cache invalidation in multi-process environments.

This work is implemented on the open-source OLAP database DuckDB v1.3.2 and systematically evaluated using standard benchmarks TPC-H and TPC-DS, along with multiple custom datasets. Experimental results demonstrate that, on TPC benchmark workloads, the system achieves an average performance improvement of 54.2\%. In targeted functional tests, it delivers an average speedup of 68.6\%, with a peak improvement of 88.2\%. The Bloom filter optimization alone contributes up to 9.3\% query acceleration. In specific test scenarios, the cross-process cache sharing mechanism achieves a maximum speedup of 264× and a performance gain of 99.61\%. The evaluation covers a wide spectrum of query complexities—from simple aggregations to intricate CTE-based queries—demonstrating the robust and consistent optimization efficacy of the proposed caching techniques across diverse analytical workloads.
