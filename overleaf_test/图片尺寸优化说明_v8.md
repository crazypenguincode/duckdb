# LaTeX图片尺寸优化说明 - v8版本

## 问题描述

在之前的版本中，导出的LaTeX文件中稍微大点的图片都会占据整个页面，上下无法填充文字，导致排版效果不佳。

## 问题原因分析

1. **图片宽度设置过大**：
   - 流程图、架构图使用 `1\textwidth`（100%页面宽度）
   - 对比图使用 `0.95\textwidth`（95%页面宽度）
   - 普通图片使用 `0.9\textwidth`（90%页面宽度）
   - 手动图片使用 `0.8\textwidth`（80%页面宽度）

2. **LaTeX浮动体参数不合理**：
   - `\textfraction{0.07}` 页面文本最小比例过低（仅7%）
   - `\topfraction{0.9}` 和 `\bottomfraction{0.8}` 浮动体比例过高
   - `\floatpagefraction{0.7}` 浮动页面阈值过低

## v8版本解决方案

### 1. 优化图片宽度设置

```python
# 根据图片大小和内容选择合适的宽度 - 优化尺寸避免占整页
if "流程" in clean_title or "架构" in clean_title or "框架" in clean_title:
    width = "0.75\\textwidth"  # 减小到75%，避免占整页
elif "对比" in clean_title or "比较" in clean_title:
    width = "0.7\\textwidth"   # 减小到70%
else:
    width = "0.65\\textwidth"  # 减小到65%
```

**手动图片优化**：
```python
# 生成LaTeX图片代码 - 优化手动图片尺寸
\includegraphics[width=0.6\textwidth]{images-man/{image_filename}}
```

### 2. 优化LaTeX浮动体参数

```latex
% 浮动体参数优化 - 避免图片占整页，促进文图混排
\renewcommand{\topfraction}{0.7}        % 页面顶部浮动体最大比例（降低）
\renewcommand{\bottomfraction}{0.7}     % 页面底部浮动体最大比例（降低）
\setcounter{topnumber}{2}                % 页面顶部最多浮动体数量（减少）
\setcounter{bottomnumber}{2}             % 页面底部最多浮动体数量（减少）
\setcounter{totalnumber}{3}              % 每页最多浮动体总数（减少）
\renewcommand{\textfraction}{0.2}       % 页面文本最小比例（增加，确保有足够文字）
\renewcommand{\floatpagefraction}{0.85} % 浮动页面浮动体最小比例（提高，减少单独浮动页）
```
